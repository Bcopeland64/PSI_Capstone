# Cyber Study Planner

Cyber Study Planner is a Python command-line application that helps cybersecurity students organize their study tasks.

## Features

- Add study tasks
- View study tasks
- Complete tasks
- Delete tasks
- Save tasks using JSON
- Load saved tasks automatically
- Get a study tip using an external API
- Input validation
- Error handling

## Technologies

- Python
- JSON
- Requests
- Pytest
- REST API
