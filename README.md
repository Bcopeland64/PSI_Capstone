# Book Scraper & Insights Tool

## Project Overview
This project is an ethical Web Scraper built as a Capstone assignment. It fetches quote/book data from a sandbox website, processes the text, performs basic analysis using Pandas, and saves the structured output into a CSV file.

## Project Structure
- `data/`: Contains the generated CSV files.
- `src/main.py`: Entry point of the application.
- `src/logic.py`: Core OOP components for scraping and processing.
- `src/utils.py`: Input validation and helper functions.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python src/main.py`
