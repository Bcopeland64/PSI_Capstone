# Capstone Project - Data Analytics & Automation Pipeline

## Description
An end-to-end Python script that fetches dynamic JSON data from an external API, performs data cleaning using Pandas, persists structured outputs to CSV, and generates visual summary reports.

## Structure
- `src/`: Source code modules (`main.py`, `logic.py`, `utils.py`)
- `data/`: Storage for output data and charts
- `tests/`: Automated unit tests
